古8
咖啡

三十年的職人手藝，堅持手工挑豆
呈現給您最好的咖啡品質

古8咖啡是由丁長興老師所創立的咖啡品牌，丁老師有30多年的咖啡烘豆經驗，不只在商用批發的咖啡配豆，到世界各地的單品咖啡豆，丁老師都有非常豐富的烘焙經驗。

古8咖啡不只單做咖啡店，我們的主要銷售項目為咖啡豆批發，目前丁老師所常用的烘豆機為—Probat 25公斤、Fuji 5公斤及1公斤三款烘豆機，每月產能為三公餘噸。

古8咖啡的信念也是丁老師在咖啡路上一直以來的堅持，就是要讓客戶喝到最新鮮的咖啡、要讓客戶擁有最完美的咖啡豆配方、要讓客戶能有最多種類的咖啡豆選擇。
